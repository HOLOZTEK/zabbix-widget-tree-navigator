# zabbix-widget-tree-navigator

[English](README.md) | 日本語

Zabbix ダッシュボードウィジェット — ホストグループとホストを折りたたみ可能なディレクトリツリー形式で表示し、選択したグループ・ホストを他のウィジェットへブロードキャストするナビゲーターです。

## Preview

### シングル選択: グループ

<img src="screenshots/tree-navigator-single-group.png" width="360" alt="シングル選択のグループモードで表示した Tree Navigator ウィジェット" />

グループモードは、ダッシュボードをホストグループ単位で絞り込みたい場合に使います。グループをクリックすると、選択したグループと配下グループの ID をブロードキャストし、マップ、グラフ、その他のパネルを選択した階層に連動できます。

### シングル選択: グループとホスト

<img src="screenshots/tree-navigator-single-group-host.png" width="360" alt="シングル選択のグループとホストモードで表示した Tree Navigator ウィジェット" />

グループ配下のホストまでたどりたい場合は、ホストグループとホストモードを使います。ホストを選択するとホスト ID を、グループを選択するとホストグループ ID をブロードキャストするため、広い単位の絞り込みと個別ホストの絞り込みを同じウィジェットで扱えます。

### ホスト検索

<img src="screenshots/tree-navigator-search.png" width="360" alt="Tree Navigator ウィジェットのホスト検索候補" />

検索ボックスでは、キーワードでホストを検索し、該当するツリーノードへ直接移動できます。候補に一致したホストが表示され、必要な親グループが自動的に展開されるため、大きな階層でも手作業で枝を開いて探す必要がありません。

### マルチ選択: グループとホスト

<img src="screenshots/tree-navigator-multi-group-host.png" width="360" alt="マルチ選択のグループとホストモードで表示した Tree Navigator ウィジェット" />

複数のグループやホストをまとめて連携したい場合は、マルチ選択モードを使います。チェックしたホストやグループは即時にブロードキャストされ、同じホストやグループがツリー内に複数表示される場合もチェック状態が同期されます。

### 設定画面

<img src="screenshots/tree-navigator-settings-ja.png" width="480" alt="Tree Navigator ウィジェットの日本語設定フォーム" />

設定画面では、ツリーのルート名、表示モード、対象グループ、初期展開深さ、下位グループの扱い、ホスト数ツールチップ、フォルダ文字色、ホスト文字色を調整できます。

## ダッシュボード連携例

<img src="screenshots/tree-navigator-dashboard-example.png" width="750" alt="Tree Navigator から他の Zabbix ダッシュボードウィジェットを連動する例" />

Tree Navigator は、ダッシュボード上のナビゲーション用ウィジェットとして使えます。グループやホストを選択すると、Zabbix ダッシュボードの動的パラメータを通じて連携先ウィジェットが更新され、マップ、状態サマリ、グラフ、その他のパネルをツリー選択に合わせて切り替えられます。

## 機能ハイライト

### ホストグループをツリーで把握

Tree Navigator は、Zabbix のホストグループを折りたたみ可能なツリーとして表示します。階層化されたホストグループを必要な範囲だけ展開できるため、監視対象が多い環境でもダッシュボードを見通しよく保てます。

### ホストまで素早く移動

ホストグループ配下のホストも同じツリー内に表示できます。ホストアイコン、ホスト数ツールチップ、検索ボックスを使って、目的のホストへ素早く移動できます。

### 他のダッシュボードウィジェットと連携

ホストグループまたはホストを選択すると、動的パラメータとして他のウィジェットへ ID をブロードキャストします。シングル選択は素早い絞り込みに、マルチ選択は複数のホストやグループをまとめて連携したい場合に使えます。

### 表示を環境に合わせて調整

設定画面から、ルート名、表示モード、対象ホストグループ、初期展開深さ、下位グループの扱い、ホスト数ツールチップ、フォルダ文字色、ホスト文字色を調整できます。

## 機能

- ホストグループとホストをツリー構造で一覧表示
- ノードのクリックでグループ ID / ホスト ID を他のウィジェットへ配信（ブロードキャスト）
- 表示モード切替：ホストグループのみ / ホストグループとホスト
- ルート名・初期展開深さ・対象グループを設定可能
- 下位グループを再帰的に含めるオプション
- ホバーツールチップにホスト数を表示するオプション
- フォルダ文字色・ホスト文字色の個別設定
- キーワード検索による候補表示と該当ホストへのジャンプ
- シングル / マルチ選択切替（ツールバーのトグルボタン）。マルチ選択時はホスト・ホスト
  グループのアイコン左側にチェックボックスが表示され、チェックしたホスト・グループの
  ID を都度即時ブロードキャスト（ホスト・グループの混在チェック可、親子連動なし）
- 日本語 / 英語対応

## 設定項目

| 項目 | 説明 |
|------|------|
| ルート名 | ツリー最上位に表示するラベル |
| 表示モード | ホストグループのみ / ホストグループとホスト |
| ホストグループ | 表示対象グループを絞り込む（未指定で全グループ） |
| 初期展開階層 | 初期展開する階層深さ（0〜10、デフォルト 1） |
| サブグループを含める | 下位グループを再帰的に含める |
| ツールチップにホスト件数を表示 | ホバー時にホスト件数を表示 |
| フォルダ文字色 | ホストグループとルートラベルの文字色 |
| ホスト文字色 | ホストラベルの文字色 |

## 出力（ブロードキャスト）

- 選択したホストグループ ID（単一）
- 選択したホストグループ ID（複数）
- 選択したホスト ID（単一）
- 選択したホスト ID（複数）

シングル選択時は、選択したグループ自身のIDに加え、`サブグループを含める` の設定に関わらず
全階層ベースの子孫グループ ID を配信します（`サブグループを含める` は子孫ノードの自動展開
という表示上の挙動のみを制御します）。

マルチ選択時は、チェックしたグループ自身の ID のみを配信します（子孫グループへの展開は
行いません）。ホスト・グループのチェックボックスは混在可能で、チェック状態の変更ごとに
即時ブロードキャストされます。

ホスト ID は、標準の Host navigator ウィジェット等との互換性のため、単一・複数どちらの
出力にも同じ選択内容（シングル選択時は選択した1件、マルチ選択時はチェックした全件）を
配信します。

## 動作要件

- Zabbix 7.0 以上
- PHP 8.0 以上

## インストール

### RPM からインストール

1. RPM をダウンロードし、Zabbix サーバーにインストール
   ```bash
   rpm -Uvh zabbix-widget-tree-navigator-*.rpm
   ```
2. Zabbix 管理画面 -> 管理 -> モジュール からモジュールを有効化
3. ダッシュボードにウィジェットを追加

### ソースから配置

1. このリポジトリの内容を Zabbix フロントエンドのモジュールディレクトリへ配置
   ```text
   /usr/share/zabbix/modules/tree-navigator
   ```
2. ファイル所有者と権限を Zabbix フロントエンドから読み取れる状態に設定
3. Zabbix 管理画面 -> 管理 -> モジュール からモジュールを有効化
