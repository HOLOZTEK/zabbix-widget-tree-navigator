# Security Policy

## Supported Versions

Security fixes are prepared for the latest published version.

| Version | Supported |
| ------- | --------- |
| 1.4.x   | Yes       |
| < 1.4   | No        |

## Reporting a Vulnerability

Do not disclose suspected vulnerabilities in a public issue before maintainers have had time to assess them.

Please report:

- affected version
- Zabbix and PHP versions
- reproduction steps
- expected impact
- any relevant logs or screenshots with secrets removed

Maintainers will review the report, determine impact, and coordinate a fix or disclosure plan.
